# Interrupted pair — excluded from campaign analysis

These are individually completed synthetic benchmark results from a pair separated by an interruption
(or whose other mode never completed). They are retained for audit, and are not paired observations.
Both modes were rerun together because of chronology/completeness, without inspecting memory results
to select runs. The analyzed collection contains the replacement results; pair-restarts.txt and
chronology-provenance.txt record this repair. Only sanitized afterIdleGc snapshots and JSON are retained.
